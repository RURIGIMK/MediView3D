# Checkpoint 1 — Technical Foundation

## Scope
Demonstrate standard C++ implementations of line drawing, polygon clipping and filling, circles and ellipses, and Bézier/spline curves. OpenGL is used to visualize results, not to implement the algorithms.

## Acceptance checklist
- [ ] Configure and build the pure C++ targets with CMake.
- [ ] Run CTest and capture passing output.
- [ ] Demonstrate DDA and Bresenham lines.
- [ ] Demonstrate polygon clipping and scanline filling.
- [ ] Demonstrate midpoint circle and ellipse algorithms.
- [ ] Demonstrate cubic Bézier and Catmull–Rom spline curves.
- [ ] Build and run the OpenGL demo on a group member's computer.
- [ ] Capture genuine screenshots of each graphical output.
- [ ] Verify README, source files, commit history and issues are visible to the lecturer.
- [ ] Submit one Google Form for the group.

## Evidence
Capture screenshots from the real running program and store them in `evidence/`. Do not use mock-ups as implementation evidence.

## Current boundary
The anatomy illustration is schematic. A complete 3D anatomical model, 3D navigation, explode view, and true 3D cross-section are future work.
