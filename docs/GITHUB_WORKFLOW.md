# Suggested GitHub workflow

1. Add group members as collaborators if appropriate.
2. Create issues for each graphics technique and for integration/testing.
3. Each member should use a feature branch for assigned work.
4. Make small commits that describe real changes.
5. Open pull requests and ask another member to review.
6. Merge only after the build and tests pass.
7. Before submission, verify the README, source files, issues, commits and evidence are accessible.

Do not manufacture commit history or commit on behalf of another group member.
